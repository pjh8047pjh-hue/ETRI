Ultra96-V2 · Inipro Pmod96

UART 기반 8×8 곱셈기

picocom에서 hex 문자로 두 개의 바이트 값을 입력하면, PL(Programmable Logic)에 새로 설계한 UART와 4bit 부분곱 곱셈기가 이를 받아 곱셈을 수행하고, 결과를 다시 hex 문자로 돌려보낸다.

01 클럭 구조

Pmod96 보드의 온보드 오실레이터는 40 MHz다. 모든 UART/곱셈기 타이밍 파라미터가 100 MHz 기준으로 설계되어 있어, Clocking Wizard로 한 번 변환한 뒤 그 결과를 내부 시스템 클럭으로 통일해서 쓴다.

40 MHz 온보드 오실레이터 (clk)
→
clk_wiz_0 MMCM/PLL
→
100 MHz sys_clk (내부 시스템 클럭)

02 데이터 흐름

RX와 TX 모두 sys_clk 도메인에서 동작하고, baudrate_gen이 만드는 1클럭짜리 baud_tick을 enable로 받아 115200 baud 타이밍을 맞춘다.

picocom hex 입력
→
uart_rx mid-bit 샘플링
→
uart_mul_ctrl 니블 조립 · 시퀀싱
→
FSM_mul + shifter + adder 4bit 부분곱 누산
→
uart_tx 결과 프레이밍
→
picocom hex 출력

03 통신 프로토콜

한 바이트를 hex 두 자리로, 두 바이트(a, b)를 이어서 총 네 글자 입력한다. 줄바꿈은 필요 없다 — 네 번째 문자가 들어오는 순간 곱셈이 시작된다.

1
a 상위 니블
2
a 하위 니블
3
b 상위 니블
4
b 하위 니블
# picocom -b 115200 /dev/ttyUSBx
1234=03A8 0x12 × 0x34 = 0x03A8
ffff=FE01 0xFF × 0xFF = 0xFE01
ab02=0156 0xAB × 0x02 = 0x0156

04 모듈 구성

파일역할
top_mul_4bit.v최상위 — clk_wiz_0, POR 리셋, 전체 배선
uart_rx.vmid-bit 샘플링 UART 수신, 메타스터빌리티 동기화
uart_tx.venable 기반 UART 송신, busy 핸드셰이크
baudrate_gen.vsys_clk을 나눠 115200 baud tick 생성
uart_mul_ctrl.vhex 니블 조립 → 곱셈 트리거 → 결과 hex 포맷팅
FSM_mul.vCALC_0~3 상태로 4bit 부분곱 시퀀스 제어
selector.v / mul_4bit.v / shifter.v니블 선택 · 부분곱 계산 · 시프트
adder.v부분곱 누산 → 16bit 결과
WIDTH = 8, CHUNK = 4 · Pmod A: rx_data (F7) / tx_data (F8), Bank 26 @ 1.8V
